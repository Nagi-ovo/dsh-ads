# 给自己的插件投个广告

这个插件会把 `dsh-external` 里最近两周更新过的插件，自动画成 2005 年风格的横幅塞进广告位。**你什么都不用做就已经在轮播里了** —— 名字和一句话简介会被自动排版成一张花花绿绿的图。

不满意自动生成的效果，可以发 PR 覆盖它。

## 只改文案（推荐，最省事）

在这个目录下加一个 `<你的插件名>.json`：

```json
{
  "repo": "dsh-external/dsh-visualize",
  "headline": "模型直接给你画界面",
  "sub": "对话里长出可交互卡片，不是贴一段代码",
  "badge": "本站强推",
  "button": "立即安装",
  "palette": 2
}
```

`repo` 必填，其余都可以省。`palette` 是 0–5 的配色编号，超出范围会绕回去。

## 想自己出图

把图放在同一个目录，文件名和 json 同名，然后在 json 里写上 `image`：

```json
{
  "repo": "dsh-external/your-plugin",
  "image": "your-plugin.webp"
}
```

支持 `.webp` / `.png` / `.gif`（动图会动，这很符合这个插件的气质）。尺寸建议二选一：

- 横幅 720×112 左右
- 竖版 300×480 左右

单张控制在 200 KB 以内 —— 素材是 base64 内联进前端包的，太大所有人都要下。

## 有几条底线

图里**不要出现真实人物和真实品牌**，具体域名请打码。这是个玩梗插件，别让它看起来像真有这么个服务。

审的时候只看这两点：不违反上面这条，以及图能正常显示。文案多离谱都行。
