# dsh-ads

给 DSH Web UI 装一层 2005 年的中文站点广告：会话越开越久，横幅越长越多，右下角"嘀嘀"弹出消息窗，左下角还会响着铃声推《贪玩蓝鲸》——而每个 ✕ 的**真实可点区域都比你看见的那个叉小，还偏**。点歪了，广告就整屏放大给你看。

> 这是个玩笑插件。它认真的地方只有两处：**永远不遮住输入框和会话列表**，以及**「关闭所有广告」是真的关**。

| 广告位 | 行为 |
|---|---|
| 两侧广告栏 | 正文列左右各一栏，同宽对齐、自上而下堆；横版占满栏宽，两个竖版并排恰好也是一栏宽（竖版永远成对出现同一张，等高不留豁口） |
| 对话内信息流 | 每两轮在助手消息正文和操作按钮之间插一条，带「广告」小标签——这条是真的在对话里，不是浮层 |
| 右下角弹窗 | 古早窗体「DSH 消息中心」+ 两声消息提示音，12 秒自动缩回 |
| 左下角海报 | 《贪玩蓝鲸》页游大图 + 双音电话铃，20 秒缩回；跟右下角永不同角，互不打架 |
| 落地页 | 没点中真热区就整屏放大，3 秒后出现正常大小的「跳过广告」，Esc 随时可退 |

## 假关闭叉

每种广告的 ✕ 都是画出来 16–20px，真正生效的只有里面一小块：

| 广告位 | 视觉 ✕ | 真实热区 |
|---|---|---|
| 两侧广告栏 / 对话内 | 20px | 7px |
| 右下角弹窗 | 16px | 5px |
| 左下角海报 | 18px | 4px |

热区的偏移量在广告出生时定死，不会在两次点击之间乱跳——会跳的话就成了渲染 bug，不是玩笑。热区永远落在视觉 ✕ 内部，所以肯用力瞄的人一定点得中。

## 它怎么维持

**打开就是满编**——14 条一次性铺开，没有前戏。这一屏就是稳态。

关掉一条，那个位置**空 15 秒**，然后补一条新的进来。所以单个 ✕ 买到的是十几秒安静，不是进展；数量始终会回到 14。

对话内信息流每两轮一条，跟着 turn 的 `seq` 走，所以同一轮永远是同一条广告——滚动来回时它不会变来变去。

右下角弹窗 45 秒一轮，横幅越多来得越勤；左下角海报 2 分钟一轮，是最重的一击。两者永不同角。

**「关闭所有广告」是唯一说真话的按钮**：点一次，这个页面直到刷新为止不再有任何广告。没有倒计时，没有翻倍，没有偷偷回来。

## 它不挡什么

浮动广告只出现在正文列**两侧的留白**里，四个边界全部运行时实测（shell 的 class 名是每次构建变的 hash，只能按几何特征认）：

- **正文列**：以输入框卡片的左右边界为准，两边各放宽 24px。正文里要广告的话，走对话内信息流那条，不浮在上面。
- **输入框**：找 `textarea` / `contenteditable` 的顶边，测不到就保守留 200px。
- **会话侧边栏**：贴左边、超过六成视口高、宽 120–400px 的元素。侧边栏是导航，埋掉它是让人没法用，不是让人烦。
- **顶部标题栏和标签页**：贴顶、够宽、高度小于 90px 的元素，取最靠下的那个边。

放不下的广告直接不画，而不是压在别的广告上。关掉一条，下面的会往上顶，原本被挤掉的那条就露出来了——"慢慢长回来"这个效果是布局自带的，不用额外写。

## 尺寸怎么定

栏宽吃满留白，上限 400px，两侧取较窄的那个值，所以左右两栏永远一样宽。

下限 **150px**：再窄下去图上的中文在 14 寸屏上就糊了，而没人看得清的广告只是噪音。留白撑不到 150px 的窗口**干脆不画侧栏**——对话内信息流和两个角落弹窗在窄窗口照样工作。

素材池（8 张）比广告位（14 个）少，重复不可避免。补位时从**出现次数最少**的那批里抽，保证每张都露过面再有第三次重复。

## 声音

用 Web Audio 合成，不带音频文件：右下角是两声上行方波"嘀-嘀"，左下角是重复两次的双音铃。那个年代真正的提示音都是别人的版权素材，不适合打包进仓库；方波在这里效果一样。四边横幅始终静音。

## 安装

构建产物随仓库分发（`lib/` 已提交），无 install、无 build、无运行时依赖：

```sh
git clone https://github.com/dsh-external/dsh-ads.git
dsh plugin --profile web add link:/path/to/dsh-ads
# 重启 dsh web，刷新页面
```

配置行由 bundle patch 自动插入，无需手动编辑 cordis.patch.yml。

## 调参

节奏与热区大小都是 `src/client/` 里的常量——纯 UI 插件没有从 host 传配置到浏览器的通道，放一份服务端 `Config` 只会在启动时校验完就无处可去。

| 常量 | 位置 | 默认 |
|---|---|---|
| `DEFAULT_SPAWN` | `schedule.ts` | 满编 14 条，补员冷却 15000ms |
| `DEFAULT_POPUP_INTERVAL_MS` | `index.tsx` | 45000 |
| `DEFAULT_POSTER_INTERVAL_MS` | `index.tsx` | 120000 |
| `DEFAULT_HITBOX_PX` | `hitbox.ts` | 7 |

## 素材

三套素材，用途不同：

- `assets/ads/` —— 扁平边条与竖幅，走四条边。
- `assets/popups/` —— 满屏彩色大图，走右下角弹窗，按文件序轮换。
- `assets/posters/` —— 页游海报，走左下角，按文件序轮换。

改图或加图之后跑 `pnpm run assets` 重新生成 `src/client/builtin-ads.ts`（图片以 data URI 内联进客户端包，因此不需要静态资源路由，也不用动 CSP）。素材里的品牌、域名、人物全是虚构的，域名一律打码。

开发者改源码后：`pnpm install && pnpm run check`（typecheck + 测试 + 重新构建 `lib/`）。

灵感来自那个年代每个下载站的右下角。
